# ملفات n8n لموازنة

هذه ملفات مستقلة وجديدة لربط النسخة الحالية من تطبيق موازنة. لا تحتوي على كلمات مرور أو مفاتيح أو أرقام واتساب، ويمكن استيرادها بأمان إلى n8n.

## الاستيراد

من صفحة **Workflows** في n8n، اختر **Import from File** ثم استورد الملفين:

- `01-اعتماد-السحوبات-تيليجرام.json`
- `02-اعتماد-السداد-تيليجرام.json`

اترك مساري العمل غير مفعّلين حتى تنهي الإعداد التالي.

## بيانات الاعتماد في n8n

اربط كل عقدة مطلوبة بالاعتماد المناسب بعد الاستيراد:

| العقدة | نوع الاعتماد | الإعداد |
| --- | --- | --- |
| `طلب موافقة تليجرام` | Telegram API | بوت تيليجرام الذي أضفته إلى مجموعة مسؤولي الاعتماد. |
| `اعتماد…` و`رفض…` | HTTP Basic Auth | مستخدم WordPress الخدمي وApplication Password له. |

## متغيرات بيئة n8n

أضف هذه القيم إلى بيئة خادم n8n ثم أعد تشغيله:

```text
MUWAZANA_TELEGRAM_CHAT_ID=-1001234567890
```

رابط ووردبريس موجود مباشرة داخل عقدتي `اعتماد السحب` و`رفض السحب`، لأن خادم n8n الحالي يمنع قراءة متغيرات البيئة داخل التعبيرات. عند استخدام بيئة اختبار، غيّر نطاق الرابط في العقدتين إلى موقع الاختبار قبل التفعيل.

## ربط WordPress بالويبهوك

أضف روابط **Production** إلى ملف `wp-config.php` الخاص بنفس بيئة WordPress، قبل السطر `/* That's all, stop editing! */`:

```php
define('MUWAZANA_EXPENSE_APPROVAL_WEBHOOK_URL', 'https://automate.novalnk.com/webhook/mowazana-expense-approval');
define('MUWAZANA_PAYMENT_APPROVAL_WEBHOOK_URL', 'https://automate.novalnk.com/webhook/mowazana-payment-approval');
```

لا تضف هذه القيم إلى Vercel. لكل بيئة WordPress رابطها الخاص: استخدم روابط n8n التجريبية في بيئة الاختبار، وروابط الإنتاج في البيئة الحية. الويبهوك لا يحتاج كلمة مرور أو ترويسة سرية.

## اختبار قبل التفعيل

1. استخدم **Test step** على عقدة `Webhook` وأرسل طلبًا تجريبيًا يحمل حدثًا مطابقًا للمسار.
2. تأكد من وصول رسالة اعتماد إلى مجموعة تيليجرام.
3. جرّب الرفض أولًا وتأكد من أن العملية تصبح `rejected` في WordPress.
4. بعد ذلك جرّب الاعتماد وتأكد من تحولها إلى `approved`.
5. فعّل مسار العمل وتأكد من وضع رابط **Production URL** في `wp-config.php` للبيئة نفسها.

لا تستورد ملفات `mowazana_files/n8n` القديمة بدلًا من هذه النسخ؛ هي ملفات سابقة أضيفت للمشروع وليست جزءًا من هذه الحزمة الجديدة.
